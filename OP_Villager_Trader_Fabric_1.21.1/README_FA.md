# OP Villager Trader — Fabric 1.21.1

این پروژه سورس یک ماد Fabric برای Minecraft Java 1.21.1 است.

## قابلیت‌ها
- دستور `/optrader` یک ویلیجر فروشنده با نام OP Item Trader می‌سازد.
- آیتم‌های ثبت‌شده در رجیستری بازی (از جمله بسیاری از آیتم‌های مادهای دیگر) به‌صورت داینامیک به لیست معامله اضافه می‌شوند.
- قیمت هر معامله دقیقاً ۱ عدد Dirt است.
- زره‌ها و ابزارهای کاربردیِ قابل‌انچنت، انچنت‌های مناسب و قوی می‌گیرند.
- برای ایمنی، آیتم‌های جنگی مانند شمشیر، تبر، کمان، کراسبو، نیزه و گرز عمداً از فروشگاه حذف شده‌اند؛ بنابراین این نسخه ادعای «تمام آیتم‌ها بدون استثنا» ندارد.

## ساخت فایل JAR
1. Java 21 (JDK) نصب کن.
2. Fabric Loader و Fabric API نسخه سازگار با Minecraft 1.21.1 را نصب کن.
3. این پوشه را با IntelliJ IDEA یا ترمینال باز کن.
4. دستور `gradle build` را اجرا کن.
5. فایل خروجی در `build/libs/op-villager-trader-1.0.0.jar` ساخته می‌شود.
6. فایل JAR را داخل پوشه `mods` قرار بده.

## استفاده
در دنیای تک‌نفره با Cheats روشن یا در سرور با دسترسی OP، دستور زیر را اجرا کن:

`/optrader`

**نکته:** این بسته سورس پروژه است، نه فایل JAR کامپایل‌شده. برای ساخت JAR باید Gradle وابستگی‌ها را دریافت کند.
